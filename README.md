9was9. Версия 0.2.0. Автор CharmLxt (PyPI: CharmLxt, email: reception.mailspypi@gmail.com). Ссылка на GitHub: https://github.com/CharmLxt/9was9.



Важно про имя пакета. Установка производится командой pip install 9was9 (так пакет называется на PyPI), но импортировать его нужно как ninewas9, потому что имена Python-модулей не могут начинаться с цифры. Пример: from ninewas9 import KVCache, RoPECache, FusedLinear, fast\_softmax, image\_ops.



9was9 — это универсальная библиотека-ускоритель для numpy-вычислений, созданная в первую очередь для нейросетевого инференса, но применимая в любом проекте, где важна скорость работы с массивами. В основе лежит несколько идей: предвыделение памяти вместо повторяющихся аллокаций, кэширование часто используемых таблиц, объединение нескольких матричных умножений в одно, и численно стабильные реализации классических операций. Вся библиотека работает на чистом numpy без единой внешней зависимости. Версия 0.2.0 полностью совместима с новым NumPy 2.x.



В этой версии добавлен модуль image\_ops, который предназначен для тонких задач обработки изображений (например, для стриминга экрана или работы с видеопотоком). Он не заменяет тяжелые библиотеки вроде OpenCV или Pillow, но дает базовые и очень быстрые операции на чистом numpy. В частности, доступны: fast\_resize (быстрое изменение размера через nearest neighbor), block\_downsample (усреднение блоков пикселей для понижения разрешения), rgb\_to\_grayscale (перевод в оттенки серого), rgb\_to\_bgr (смена красного и синего каналов, полезно для скриншотов Windows), normalize\_image (нормализация пикселей в диапазон от 0 до 1) и pad\_image (добавление полей к картинке). Все функции работают с массивами формы (Height, Width, Channels) и возвращают новые массивы.



Основные модули остались прежними. KVCache — это менеджер памяти для ключей и значений в трансформерах, который заранее выделяет буфер максимального размера и записывает новые значения в срез, избегая np.concatenate на каждом токене. RoPECache предвычисляет sin и cos таблицы для Rotary Position Embeddings с поддержкой нескольких типов масштабирования. FusedLinear объединяет несколько линейных слоёв в одно матричное умножение. Fast-softmax содержит численно стабильные реализации softmax, log-softmax, causal mask, scaled dot-product attention с поддержкой GQA и MQA через broadcast, а также top-k и top-p фильтры для сэмплинга.



Установка: pip install 9was9. Зависимость только одна — numpy. Библиотека не требует torch или tensorflow. Все функции работают с обычными numpy-массивами и не имеют побочных эффектов. Связь с автором: reception.mailspypi@gmail.com.
